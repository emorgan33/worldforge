# WorldForge v0.4.0

This release improves navigation across the author workspace and reader pages.
The campaign sidebar can collapse on desktop, and mobile users can open campaign
navigation in a drawer. The World contents section remains scrollable without a
visible scrollbar.

Public and campaign readers now share responsive article browsing. Wide screens
show the category tree beside world or article content; narrow screens provide
a **Browse articles** control. Readers can navigate to the world home, expand or
collapse category branches, follow article breadcrumbs, and search readable
article titles and excerpts. Public and campaign access rules remain separate.

See the [reader navigation and discovery guide](https://github.com/emorgan33/worldforge/blob/v0.4.0/docs/reader-navigation-and-discovery.md)
for route behavior, access boundaries, and verification details.

## Upgrade

Back up the SQLite database and asset directory before upgrading. No database
migration is required.

For an installation tracking `main`:

```bash
git pull
docker compose up -d --build
```

For an installation pinned to a release tag:

```bash
git fetch --tags
git checkout v0.4.0
docker compose up -d --build
```

The persistent database and uploaded assets remain in the Docker volume.
