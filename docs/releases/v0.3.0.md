# WorldForge v0.3.0

This release adds interactive character sheets to Character articles in D&D 5e
2014 and Pathfinder 2e Remaster worlds. The editable sheet includes identity,
attributes, defenses, skills, saves, attacks, equipment, features, spells,
resources, and system-specific sections. Repeatable sections support adding,
editing, removing, and undoing row removal.

D&D ability modifiers are calculated from ability scores. Other totals remain
manual entry. Class, level, training, and attribute changes do not automatically
build or recalculate a character. This release provides character sheets, not a
full rules-aware character builder.

Sheets use the article's existing metadata, preserve prose and legacy values,
and require no database migration or reseeding. Existing autosave, local draft
recovery, revisions, and world export/import continue to preserve sheet data.
Published readers receive a read-only sheet with only the active profile's
known fields and row columns. The authoring workspace also gains a mobile
navigation menu so the editor and sheet can be used on smaller screens.

See the [interactive character sheet guide](https://github.com/emorgan33/worldforge/blob/v0.3.0/docs/character-sheets.md)
for field behavior, compatibility details, and verification commands.

## Upgrade

Back up the SQLite database and asset directory before upgrading. No database
migration is required.

For an installation tracking `main`:

```bash
git pull
docker compose up -d --build
```

For an installation pinned to a release tag:

```bash
git fetch --tags
git checkout v0.3.0
docker compose up -d --build
```

The persistent database and uploaded assets remain in the Docker volume.
