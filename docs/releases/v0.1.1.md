# WorldForge v0.1.1

This patch release fixes account setup on a new installation. `auth:setup` now
creates the first GM account when the database is empty. Administrators can
create additional accounts with:

```bash
docker compose exec worldforge pnpm auth:setup -- --create you@example.com
```

Use `docker compose exec worldforge pnpm auth:setup -- you@example.com` to
recover an existing account. Each command prints a one-time setup link for
choosing an email and password. No demo seed is required to create an account.

The README and documentation now disclose that AI tools contributed to this
project. See the [AI disclosure](https://github.com/emorgan33/worldforge/blob/v0.1.1/docs/ai-disclosure.md).

To update a Docker Compose installation tracking `main`:

```bash
git pull
docker compose up -d --build
```

The persistent database and uploaded assets remain in the Docker volume.
For an installation pinned to a tag, fetch tags and check out `v0.1.1` before
rebuilding the container.
